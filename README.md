# Focus 每日中文新闻

这是 Focus 手机客户端读取的公开新闻库，整理时政、AI 新闻、游戏、数码和学术五个栏目，游戏重点关注独立游戏与 3A 大作。内容是根据公开来源核验后生成的 **AI 中文详报与播报稿**，附原始来源和相关核验链接，供阅读和手机朗读。

学术优先船舶碰撞、船–桥/风机碰撞及风机灾害；其它研究跟踪 PolyU 毕凯明、夏勇和湖南大学樊伟团队。见 [学术关注清单](ACADEMIC.md)。媒体范围包括 BBC、DW、联合早报、Reuters、AP、NPR，结合一手发布与交叉核验，见 [媒体清单](media-watchlist.json)。

稿件是独立组织的中文内容，手机可以打开来源网站继续读原文。来源的登录、订阅或摘要限制仍由来源网站决定。配图附作者、许可和原页面；栏目替代图片明确标“资料图（非现场）”。

计划按 `Asia/Hong_Kong` 时区每天 **09:00、12:00、17:00** 更新早间、午间和晚间三期。实际生成时间以文件的 `generated_at` 为准；检索、网络和发布端运行情况可能使更新延后，没有可靠新消息时本期可以为空。

- [feed.json](feed.json)：聚合新闻，最多 500 篇；年度重要优先保留，剩余容量用于最近新闻，最终按日期从新到旧排列。
- `year_highlight`：年度重要事件/研究标记，手机“年度重要”可以单独回看 2026 年里程碑。
- `latest_article_ids`：本期选择的新增或重要更新条目，保持播报顺序；手机“朗读本期”只读取这些条目。
- [archives](archives/)：按香港日期和实际生成时间保存的单期档案。
- [PUBLISHING.md](PUBLISHING.md)：来源核验、稿件边界、完整数据格式与发布流程。
- [validate-feed.mjs](validate-feed.mjs)：无第三方依赖的离线校验器，不会自行生成或发布新闻。
- [merge-feed.mjs](merge-feed.mjs)：去重、年度保留、来源映射与资料图补齐；不生成新闻。

手机匿名读取公开文件，不需要 GitHub 账号或访问令牌。收藏、已读和本机语音设置保存在手机上，不写回此库。手机后台读取还受系统联网、通知和省电策略影响，因此收到更新的时间可能晚于文件生成时间；收到新闻更新不会自动开始朗读。

仓库本身不执行新闻生成；更新由外部发布任务按计划完成。发布只包含已核验的公开新闻与说明，不存放私人资料、客户端签名文件或访问凭据。
