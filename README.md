# Focus 每日中文新闻

这是 Focus 手机客户端读取的公开新闻库，按 **1.5 发布政策**整理时政、AI、游戏、数码、影视和学术六个栏目。**每栏至少保留50篇不同的已核内容，合计至少300篇，聚合上限500篇**，兼顾近期新闻与有意义的历史回看。内容是根据公开来源核验后独立组织的 **AI 中文详报与播报稿**，附原始出处和核验链接，供阅读和手机朗读。

各栏目方向与来源入口首先见 [内容关注清单](content-watchlist.json)。游戏重点关注影之刃零、鬼武者、独立游戏与3A大作，区分试玩、预售和正式发售及平台差异。数码覆盖 Samsung/三星、vivo、Huawei/华为、Apple、NVIDIA 等多品牌，区分地区、供货阶段、官方价格与实测；AI覆盖多家模型和产品厂商。时政跟踪法德当地社会事件、塞尔维亚选举、俄乌局势、宏观经济金融与重大灾害，逐项核实地点、阶段和数据，不将提问中的措辞直接当成事实。

学术优先船舶碰撞、船–桥/风机碰撞及风机灾害；其它研究与学术消息重点为广州大学郝洪的已核团队/师承网络，并保留 PolyU 毕凯明、夏勇、湖南大学樊伟，兼顾同济、广西大学和国际土木团队的重大项目与任职动态。作者身份、论文状态和已读范围须核对，见 [学术关注清单](ACADEMIC.md)。媒体范围包括 BBC、DW、联合早报、Reuters、AP、NPR，结合一手发布与独立交叉核验，见 [媒体清单](media-watchlist.json)。

稿件突出事实、实质数据和必要背景，少量关键结论用 **粗体**标明；朗读和预览去掉格式标记。中文稿不是第三方全文或逐字翻译，手机可打开来源网站继续读原文。发布者实际阅读公开原页，搜索摘要只作线索；只读到摘要或节选时明确范围，正常来源的登录、订阅及访问限制仍由来源网站决定。

配图优先同一报道或论文的原图、图表和界面，附实际出处与归属。`source_remote` 仅链接原站，不代表获得转载许可；许可未明确时不公开复制托管。合适的同型号、同功能或同主题官方替代图标为“资料图（相关主题，非该报道原图）”，不把不同型号的成绩或旧场景冒作当前结果。已核开放许可素材可按许可署名托管。**不以统一栏目图、机房图或公司logo反复填满文章**；旧 `covers.json` 仅作兼容，无合适图时可留空。

计划按 `Asia/Hong_Kong` 时区每天 **09:00、12:00、17:00** 开始早间、午间和晚间三期检索。每期目标为15–30条可靠新增或重要更新，按实际证据决定数量，不为凑量造新闻。实际生成时间以 `generated_at` 为准；检索、网络和发布端运行情况可能使更新延后，没有可靠新消息时本期可以很少或为空。历史回填保留真实日期，不能算作今天新发生的消息。

- [feed.json](feed.json)：聚合新闻，最多500篇；保护六栏各50篇的保留底线和2026年度重要，再用剩余容量保留最近新闻，最终按真实来源日期从新到旧排列。
- `month_highlight`：月度重要标记，按真实 `published_at` 所属年月回看；年度重要也进入对应月份。
- `year_highlight`：只用于2026年重要事件/研究，手机“2026年度重要”单独回看；往年代表作须标明实际年份，不能混入该视图。
- `latest_article_ids`：本期选择的新增或重要更新条目，保持播报顺序；手机“朗读本期”只读取这些条目。
- 日期只核实到月份时保留 `YYYY-MM`，不虚补某一天；只有日期时不编造具体时分秒。
- [archives](archives/)：按香港日期和实际生成时间保存的单期档案。
- [PUBLISHING.md](PUBLISHING.md)：来源核验、稿件边界、完整数据格式与发布流程。
- [validate-feed.mjs](validate-feed.mjs)：无第三方依赖的离线校验器，不会自行生成或发布新闻。
- [merge-feed.mjs](merge-feed.mjs)：按当前发布政策去重、保留历史与重要标记、映射来源；不生成新闻，不使用旧栏目图作为新稿默认配图。

手机匿名读取公开文件，不需要 GitHub 账号或访问令牌。收藏、已读和本机语音设置保存在手机上，不写回此库。手机后台读取还受系统联网、通知和省电策略影响，因此收到更新的时间可能晚于文件生成时间；收到新闻更新不会自动开始朗读。

仓库本身不执行新闻生成；更新由外部发布任务按计划完成。发布只包含已核验的公开新闻与说明，不存放私人资料、客户端签名文件或访问凭据。


1.4 新增[影视清单](entertainment-watchlist.json)、[游戏清单](games-watchlist.json)与[学术网络清单](academic-network-watchlist.json)。影视包括未来电影、Netflix/国内外新剧口碑及经典回看，独立核对季数、样本与日期，不用预告代替成片评价。少数静态影视资料导读标 `date_basis=curated`，手机显示“整理于”，正文保留真实作品年份；其整理日期不能冒充上映日期或进入年度事件。AI界面简称“AI”，旧 `AI 新闻` 数据继续兼容；国内AI只选择有实质分量的进展。游戏新增FS、巫师、Larian与CS2/LoL重点，争议与低分原因仅少量、证据充分时报道。

1.5客户端将时政分中国/全球局势，“全部”交错展示六栏，月度仅列本月与上月；论文、会议及团队消息按已核资料收录。阅读页点图片直接缩放，重复来源段不在正文显示；原始链接、图片署名与许可仍保留。
